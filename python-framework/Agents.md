## 工程说明

此工程包含`Python`框架课程的所有课件、示例、练习题及答案。

每一个子文件夹表示一节课。

该课程面向已有`Python`语言基础、同时有其他语言（如`JavaScript`或`Java`）的企业开发经验的同学，因此在授课节奏上会更明快，因为很多概念是相通的。

课件中，无须去对比其他语言，因为你不知道学员之前接触的是什么语言，仅需关注`python`自身即可。

## 编程规范

- 所有的代码必须带类型标注

## 授课风格

课程采用**渐进式工程推进**的方式讲解，核心原则如下：

### 1. 一步一推进，从简单到完善

每一节课从一个最简可运行的版本开始，逐步迭代优化。典型节奏：

```
最简原型 → 验证可用 → 发现问题 → 抽取优化 → 完善结构 → 进入下一环节
```

例如`初识SQLAlchemy`这节课：
1. 先写一个单文件测试连接脚本（`model/main.py`）
2. 验证连接成功后，抽取`config.py`管理配置
3. 再抽取`engine.py`封装引擎创建逻辑
4. 最终形成工程化的代码结构

课件中体现每一步的**最终代码**和说明**。每一步之间的推进逻辑（为什么这么做、解决了什么问题）

### 2. 工程不离手

每一节课都基于同一个工程（`duyi-service`）推进。课程进展反映在工程代码的演变上。学员可以随时对照课件和工程代码。

> 工程位置在最后一节完课目录下，比如，当前正在制作的课件是`05. 数据操作/课件.md`，则参考的工程路径在`04. ORM/duyi-service`

### 3. 每节以小作业收尾

作业是 3-5 个概念性问题，用于巩固本节课涉及的核心概念。

## 课件生成规范

当你需要帮我生成或修改课件时：

1. 严格按照上述"渐进式工程推进"风格组织内容

4. 课件最后留 3-5 个概念性问题作为作业
